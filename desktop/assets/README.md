# FrameFlow 图标

`frameflow-app-icon.png` 是桌面图标的稳定源文件。它通过内置 `image_gen` 生成，保留原始透明度与尺寸。`desktop/build-macos.sh` 会将其缩放为标准的 1024 像素主图并生成全部 `.icns` 尺寸；源图缺失时才使用 Swift 的旧图标作为备用。

Web 的 `frameflow-icon.png` 是 128 像素浏览器图标；现有 `frameflow-icon.svg`、`frameflow-light.svg` 和 `frameflow-dark.svg` 内嵌 256 像素版本，以确保 SVG 用作图片时无需加载外部资源。

当前图标为用户选定的「俏皮眨眼」场记板：保留灰色立体场记板、金属转轴和斜纹拍板，在正面面板中央加入一只圆眼、一只闭眼和微笑嘴。源图为 1254 × 1254 像素，浅灰背景，不透明。

生成与编辑要求：

> 保持原场记板的造型、比例、材质、光照和背景，只在空白面板上添加简洁的“两眼一嘴”表情。深灰色表情带轻微内凹边缘，缩小后仍可辨认；不添加肢体、配饰、文字或选中边框。
